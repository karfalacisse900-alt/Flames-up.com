# Captro App Store Review Help

Use this as the submission checklist and copy source for App Store Connect.

## Required before "Add for Review"

1. Privacy Policy URL
   - `https://captro.app/legal/privacy`

2. Terms of Service URL
   - `https://captro.app/legal/terms`

3. Community Guidelines URL
   - `https://captro.app/legal/community-guidelines`

4. Safety & Reporting URL
   - `https://captro.app/legal/safety`

5. Build
   - Choose the newest processed TestFlight/App Store build for `com.karfala90.aura`
   - Wait for the current GitHub/TestFlight run to finish before selecting it

6. Primary Category
   - `Social Networking`

7. Secondary Category
   - `Photo & Video`

8. Age Rating questionnaire
   - Captro contains user-generated content, messaging, reporting, blocking, and moderation.
   - Answer the questionnaire honestly based on:
     - user-generated content
     - chat/messaging
     - moderation/reporting
     - blocking
     - account deletion
   - Expect Apple to rate this as a teen-or-older social app; the final rating comes from the questionnaire itself.

9. App Privacy
   - An Admin in App Store Connect must complete the App Privacy section before submission.
   - Declare the real data used by Captro, including account info, user content, usage data, diagnostics, and optional location if applicable.

## App Review Information

### Sign-in required

Yes.

### Reviewer account

Use a real reviewer test account that works in production or TestFlight review environment.

Do not submit with blank credentials.

Fill these fields in App Store Connect:

- User name: reviewer test account email or username
- Password: reviewer test account password

If Apple Sign In or Google Sign In is still being validated, provide a plain email/password review account as backup.

### Contact Information

Fill in your real contact:

- First name
- Last name
- Phone number
- Email

### Notes for App Review

Paste and adjust:

```
Captro is a social photo-sharing app with stories, messaging, saving, comments, reporting, blocking, and account deletion inside the app.

Important review notes:
- Sign in is required.
- Please use the reviewer account credentials provided above.
- Delete Account is available in Settings > Account > Delete Account.
- Report and Block are available from post/profile/comment/story actions.
- Privacy Policy: https://captro.app/legal/privacy
- Terms: https://captro.app/legal/terms
- Community Guidelines: https://captro.app/legal/community-guidelines
- Safety & Reporting: https://captro.app/legal/safety
```

## Screenshots checklist

Apple requires iPhone screenshots for the product page.

Recommended set:

1. Welcome / onboarding
2. Home feed
3. Discover
4. Story viewer
5. Profile
6. Post creation
7. Chat
8. Settings / account controls

Use real production-looking screenshots:

- no placeholder content
- no debug UI
- no blank states unless intentional
- no broken media
