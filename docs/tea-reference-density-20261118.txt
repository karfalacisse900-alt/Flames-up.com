Build issue resolved:
Five separator characters introduced by the edit had invalid UTF-8 bytes. Xcode
reported a build-service crash rather than the underlying parse error. Fixed in
125c6fe with ASCII Swift Unicode escapes. All native Swift files decode strictly
as UTF-8. A fast Swift parser preflight now catches this before the full build.
Temporary runner/toolchain changes were reverted after the actual cause was found.
