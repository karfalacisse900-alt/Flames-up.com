SCOPE
Conversation Details only: top-right author profile/avatar and a separate account-follow control; discussion-follow remains the bookmark action beside replies. Consecutive reply authors group without changing message order. Caption sentences receive revision-bound reply targets, inline collapsed threads, and the existing bottom composer with a removable quote target. Links keep their existing safe, compact hostname presentation.
Clubs only: supported member-owned group destinations from Tea open Chat, Links, Info; Rooms are optional and accessible through the header. Nonmembers retain the existing details/join flow. Events and meetups are not routed into chat. Existing Messages uses General; additional rooms do not leak into that legacy conversation.
Home, Capture, the Tea entry point/list, bottom navigation, checkout, Support, and financial behavior are unchanged. The shared cursor helper now accepts bounded legacy text message IDs only for two named Tea club scopes; existing feed cursor validation remains strict.

PERSISTENCE AND SECURITY
20261115014511_tea_sentence_replies.sql: nullable reply target JSON, immutable caption revision snapshots, service-only visibility-checked target reads/writes and independently paginated sentence threads. Existing replies remain general and old clients retain their original response contract. Target identity is revision plus Unicode code-point offsets and a quote snapshot, never a screen coordinate. Every edit increments revision; old replies appear under Earlier text, including an edit that changes only links. Historical text is never silently reattached.
20261115015247_tea_club_spaces.sql: settings, rooms, saved links, read markers, hashed invites and invitation decisions. Existing app_group_messages and memberships are reused; General is a NULL room. All new tables deny ordinary direct access. RPCs require the service role and check an active canonical actor, club membership, blocks and action-specific organizer/owner privileges. Writes lock the existing group row; stale versions and reused request identities are rejected. Announcement rooms are read-only to ordinary members. Original link sharer and link curator are recorded separately. Read cursors bind actor, club, room and query type.
Invite links expire and can be revoked. Tokens contain no identity and are stored hashed. Existing paid/approval join flows are preserved: invite approval never inserts a membership, purchase or entitlement. Clubs already requiring approval go directly to their existing request flow. Invitations cannot bypass a private profile/listing's existing visibility requirements. Signing-key rotation invalidates copying old invitations honestly instead of constructing broken links.
Read-only production catalog inspection confirmed the existing group/message/reply columns and RLS baseline. Only the original tea_conversations migration is deployed. Neither new migration has been applied to production. No customer rows were read or changed for these checks.

NATIVE STATE
Conversation presentation models retain drafts, expanded targets and a viewport through navigation. Cached details remain visible while stale data refreshes. Account change, blocking or authorization denial clears the scoped cache. Club drafts, quotes, selected tab/room and scroll identity persist per club and account. Message reads coalesce, and refreshing does not replace the chat with a full-screen loader. Older quote navigation retrieves one bounded authorized history page, with an explicit Latest messages action.
Native @mentions insert a selected member's canonical @username. There was no existing mention-notification system to reuse; this does not claim new push-notification behavior. Existing media messages keep their existing Messages destination. The new chat composer is text-only.
