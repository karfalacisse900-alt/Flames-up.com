CHANGES
- Tea list and conversation detail use CaptroBrandLogo, the existing supplied
  symbol and outlined wordmark used by Capture, at 86 x 23 pt. Light/dark artwork
  follows the current appearance. The separate Tea/cup heading is removed.
- A visible Post button opens the existing authenticated Tea composer directly.
  Its touch target is at least 44 pt. The three-dot list menu is removed.
- The existing all-activities destination remains available from Clubs/Events
  via All activities; offers, reservations and the existing actions remain.
- Tea row separators are 1 pt with an opaque neutral adaptive color. Previously
  they were 0.5 pt and only 5.5% black in light mode, making them almost invisible.
- Activity rows put the real Club/Event/Meetup/Offer/Reservation type beside the
  timestamp in violet. Nearby appears only for results from an explicitly chosen
  city query. The original API filtering, permissions and pagination are reused.
- Home's inbox shortcut is removed. Messaging services and profile access remain.

CONTEXT DATA LIMITATION
Existing general conversation records contain no city, club or event association.
They remain untagged. Neither title keywords nor the author's profile city can
truthfully establish those associations. No sample tags or fake associations were
added to production posts. Adding associations to general conversations would
require a persisted author-selected context and server authorization validation.
No database or API change is needed for this presentation update.
