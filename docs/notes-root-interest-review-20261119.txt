Implemented
- Home / Notes / Me in the existing native tab container. Home remains the default.
- Notes uses the existing Tea screen, data, filters, composer and activity routes. No root back arrow; detail back remains.
- The Home Tea shortcut selects that same Notes tab instead of creating another cover/feed instance.
- Removed the standalone Capture screen, its preview/chrome, exclusive geometry and obsolete tab tests. The shared capture service and camera permissions remain because Home post and Story creation use them.
- Existing startup coordinator now owns the root API client throughout SwiftUI reconstruction.
- Account-owned Notes list retains all successfully loaded pages; freshness (120 seconds) no longer expires displayable data after ten minutes.
- Refresh revalidates the loaded range atomically, retains content on a failed refresh, deduplicates in-flight reads, and preserves the visible row. Account/access invalidation clears private presentation state and saved positions.
- Retry repeats the failed operation: a failed refresh is retried as a refresh, rather than mistakenly loading the next page.
- Author/profile reads no longer run automatically for every detail reopen. Replies use a freshness window; sentence threads refresh on demand, explicit refresh, or a changed count.
- The split interest control has two independent 44-point targets, a small outline, no public counts, and a stacked fallback when metadata needs more width.
- Feed and detail share the same private selection, with server-acknowledged changes, undo, serialized taps and retries of the original absolute intent.
- Removed the author-header Follow plus. Profile following and discussion following remain separate working flows.
- Author-only Insights report unique authenticated opens, current interested accounts and visible active replies. Row rendering never records an open. Author opens are excluded; repeated opens are unique by account.

Backend changes, not deployed
- Additive migration: supabase/migrations/20261120005350_tea_private_interest_insights.sql
- Private app_tea_interest and app_tea_opens tables, RLS enabled, no direct anon/authenticated grants, indexed per Note and user, account-deletion cascade.
- captro_tea_private_signal verifies canonical actor, active account, Note visibility, blocking and author ownership for Insights.
- PUT /tea/conversations/:id/interest, POST /:id/open and GET /:id/insights reuse the existing authenticated Worker and rate limits.
- Existing Note JSON adds only the current viewer's selection; no public aggregate opens or interest counts.
- No changes to ranking, DMs, account follows, RSVPs, payment flags, fund routing or financial records.
