Implementation
- Existing CaptroCameraCaptureService / AVCapturePhotoOutput / MovieFileOutput
  remain the sole Capture pipeline. Preview remains the real AVCaptureVideoPreviewLayer.
  No scene image, mock camera, new capture SDK, second session or filter engine.
- Near-black chrome, white controls, yellow-green selected mode/zoom and focus.
  Top row: capability-aware photo flash/video torch, small CAPTRO, settings.
  PHOTO/VIDEO move above the white photo / red record-stop shutter. Capture's
  native tab tint/background become white/black; Home and Me retain their theme.
- Pinch routes into existing serialized setZoom; actual published zoom drives
  controls. The service currently selects the wide camera: 1x plus digital zoom
  adjustment, not invented 0.5x/2x optical lenses. No pipeline lens upgrade here.
- Tap focus uses captureDevicePointConverted(fromLayerPoint:), with a brief local
  indicator. Existing exposure control remains available after focus. Press response
  is short, with light capture/mode haptics; Reduce Motion suppresses scaling.
- Real 3/10-second photo countdown; cancel on loss of activity/interruption,
  block mode/flip/repeated capture while counting down. Service's existing capture
  admission and file-finalization guards remain authoritative.
- Recording indicator starts from AVFoundation's didStartRecording callback.
  Preparation says Starting; finalization says Saving. Capture success and thumbnail
  reveal require a returned result, not a button tap. Review/retake and Post/Story
  handoff retain the existing original and cancellation behavior.
- Settings sheet: grid, photo timer, actual active resolution/frame rate and limits.
  The current verified pipeline has one video quality (1080p/30 H.264 SDR) and
  full-resolution quality-prioritized photos, so quality is shown read-only rather
  than offering fake HD/4K/60fps switches. No new re-encoding path.
- Gallery uses the existing CaptroPostMediaPicker via system PhotosPicker. The
  thumbnail queries only already-authorized/limited Photos, off-main, no iCloud
  download, no requestAuthorization call. Unavailable thumbnail uses a real picker
  button with an icon. Import failure is explicit; no automatic publication.
