EXACT INTERFACE CHANGES
- Remove Home's Captro Business menu item and its now-unused sheet. The directory
  implementation, API, storefronts and supported routes remain.
- Tea list omits standalone business-directory rows only. Raw pages, caches and
  cursors remain intact; pagination continues through pages containing only those
  rows. Activity offers/reservations, events, meetups and clubs remain eligible.
- Visitor Plans/Clubs tabs collapse only after successful data establishes absence.
  Pending pages keep Plans visible; loading/errors are not treated as zero content.
  Owner tabs and management remain unchanged. Hidden selected tabs return to Moments.
- Remove the professional profile switch. Render authorized Creator and Business
  information together, with one introduction, real upcoming plan and shop links.
  Support no longer depends on a local profile-switch selection; approval/readiness
  checks remain unchanged.
- Hide unavailable Studio entry/placeholder. Active authorized users with a supplied
  Studio URL retain the existing server-authorized browser handoff.
- Hide seller tools only when payout setup, approved roles, business history,
  earnings, payouts and Support/category history establish no seller activity.
  Errors preserve access with Retry. Historical activity does not require an active
  professional role. Buying/payment methods and purchase/ticket history remain.
- Club photos/videos render inside the conversation through RemoteMediaView using
  the original server URL, no public fallback. Retry stays interactive. Video is
  opt-in, one selected attachment at a time, stopped when inactive/backgrounded.
  Unsupported legacy file/audio types retain the existing Messages route.
- Add a 44-point Home inbox shortcut using startup.chatModel, also used by Me.
  Guest taps use the existing sign-in path. No new tab, independent inbox model or
  messaging service. Existing media playback suspension also covers the inbox sheet.
