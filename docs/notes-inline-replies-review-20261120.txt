Implemented
Existing Note details now mark replied-to excerpts with a thin purple underline and one superscript reply count per stored sentence. Repeated “replies to this line” and “Hide replies” links are removed. Tapping the marked text/count expands replies directly below the sentence; tapping again collapses it, and opening another sentence closes the first. All threads begin collapsed.

Overlapping excerpts share a marker without duplicating replies. Each reply retains its original quote. Original Unicode-scalar anchors and caption versions are used; edited/removed source text remains identifiable as Earlier text. No matching by wrapped screen line or fuzzy quote matching.

Reply bodies load only on expansion, five at a time with Load more. Existing caches, account scoping, access checks, request cancellation and stale-response guards are retained. General replies, drafts, native excerpt selection, bookmark, interest pill, engagement, profiles and link opening remain. The separate Note composer design was not changed.
