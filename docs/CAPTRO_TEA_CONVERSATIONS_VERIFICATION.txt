API / privacy contract
GET /tea/conversations: eligible posts, 20 per page, signed viewer-bound cursor.
GET /tea/conversations/:id: revalidated detail.
GET /tea/conversations/:id/replies: eligible replies with parent-bound cursor.
POST /tea/conversations: request_id, title, body, links.
PUT /tea/conversations/:id: title, body, links, expected version.
POST /tea/conversations/:id/replies: request_id, body.
PUT /tea/conversations/:id/follow: desired following boolean.
The existing Swift encoder uses snake_case; HTTP tests exercise request_id.
Only canonical server-resolved actors can mutate data. Private-author visibility,
active follow permissions, both-direction blocks, removed content and account
status are checked on list/detail/reply routes. Responses project only the public
author ID, display name and username. Tables/RPCs deny anon/authenticated direct
access; the trusted Worker supplies identity. Follow is persisted per discussion;
this patch does not add a separate push-notification delivery system.

Links
Up to three HTTPS destinations, validated on client and server. No credentials,
local/IP hosts or nonstandard ports. URLs retain their actual query parameters;
the UI displays only the parsed hostname. Exact domain boundaries identify
YouTube/TikTok. Other sites get a tiny neutral link symbol. Supported owned-domain
profile links use existing in-app profile navigation; other HTTPS destinations
open the system browser. No arbitrary URL fetching or remote favicon service.
Platform symbols are bundled Simple Icons SVGs, template-rendered at 11 points;
the accompanying upstream license is in TeaLinkIcons-LICENSE.txt. Link controls
retain 44-point touch height and explicit VoiceOver labels.
