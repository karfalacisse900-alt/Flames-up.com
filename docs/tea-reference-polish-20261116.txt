Known source limitations (not disguised by UI):
- All currently means all conversations; all eligible activity kinds remain accessible
  in the overflow. These are separate existing services, not a fabricated unified feed.
- Following-by-author and geographically tagged conversations have no existing API.
  Nearby is explicitly city-based activities, not nearby conversation posts.
- List/reply/club-message author projections provide id/name/username only. Initials
  are shown there instead of inventing photos or performing per-row profile requests.
  Detail-author and club header use their existing real-image data.
- No link-preview title/image metadata: links use real hostname/tiny icon fallback.
- Conversation reactions and reply uploads are not supported by the current service.
  No fake heart counts, reaction buttons, camera/upload controls, or verification badges.
  Club mention, quote, links, and existing media display remain available.
- Tea is already a full-screen cover, so it does not support keeping the Home tab bar
  under its list. No duplicate/fake navigation bar was introduced.
- Files/audio still use their existing Messages destination; supported photos/videos
  remain in the club with the existing fit-aspect media player.
