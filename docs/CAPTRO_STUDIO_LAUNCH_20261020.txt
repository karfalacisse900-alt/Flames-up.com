CONFIRMED SOURCE CAUSES / CHANGES
Capture previously fitted its aspect ratio into the height remaining in a padded
vertical stack. A portrait video frame is taller than a photo frame, so fitting it
into that remaining height narrows it. The repair computes output height from the
available full width, independently anchors header/actions, reserves the video
format label row in both modes, and allows tall video behind dark controls.
The preview layer preserves aspect, never stretches. The recording-frame outline
and settings explanation identify controls that overlay the frame, not saved pixels.
Live mode changes use the configured output dimensions after serialized session
configuration; denied/unavailable states still use the intended mode proportions.

The switch control uses arrow.triangle.2.circlepath with a 52pt target and the
"Switch camera" label. Shutter centering does not depend on a gallery spacer.
Removed Capture's Photos imports, gallery state, picker presentation, picker load
task and permitted-gallery-thumbnail task. Existing post/Story pickers are untouched.
Review, retake, enhancement/original comparison and composer handoff remain.
"LIVE CAPTURE ONLY" was already absent in this checkout.
Capture-only compact navigation drives the existing TabView selection; other tabs
retain their existing navigation and layout.

Startup previously remained behind branding until session/cache preparation, with
a forced minimum interval and repeating TimelineView pulse. Essential initialization
now runs concurrently with the reveal. Branding ends immediately when routing is
ready or after a 720ms deadline plus a 180ms crossfade. Slow initialization shows
an explicit session-restoration loading state, then the existing retry/route UI.
There is no repeating logo timer or wait for every feed image/video.
Backgrounding removes the overlay without rearming it. Recovery presentation waits
for identity resolution; a pending cold profile link survives initial auth restore.
Warm recovery retains the already-mounted destination/draft. Decorative branding
is excluded from accessibility and never receives touches.

The four Startup SVG assets are mechanically separated from the approved supplied
lockup, retaining original curve paths, outlined letter paths and transforms.
The static storyboard and first-render view share a 292 x 75.92pt centered lockup,
named adaptive background and initial 0.14 opacity. Reduce Motion uses a still
logo. The welcome collage and its separate animation are not changed.
